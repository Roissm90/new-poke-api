# Type Icons

SVG originals from WikiDex's Pokemon Sword/Shield type icon collection:
https://www.wikidex.net/wiki/Archivo:Tipo_planta_icono_EP.svg
https://www.wikidex.net/wiki/Archivo:Tipo_bicho_icono_EP.svg

Each English filename corresponds to `Archivo:Tipo_<Spanish type>_icono_EP.svg`.
WikiDex credits Pokemon Zukan as the original source. File histories credit
Ciberdavid99 and Ciencia Al Poder. The SVG files are retained unmodified;
round framing is applied through CSS, not by changing the original drawings.
